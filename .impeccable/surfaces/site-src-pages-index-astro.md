# Lucia marketing + docs site

Scope: `site/` Astro static site on GitHub Pages (`https://seiggy.github.io/lucia.os/`). Landing page = Persuade. `/docs/*` (index included) = Read.

Audience: engineers already running a homelab, tired of care and feeding. Job: understand what Lucia does and what it assumes, then install from source or star the repo. Desktop bootstrap shows as COMING SOON with no link.

Proof: real screenshots of the live lab UI (hostnames and node names allowed, never secrets), each carrying a provenance plate. Tube numerals show only spec values traceable to code. No counters, uptime, benchmarks, testimonials, or user counts.

Voice: fun and tongue-in-cheek, engineer to engineer. Every joke rests on a true fact. Unfinished work is admitted plainly.

Constraints: MIT license. README stays as is. Owner-generated imagery is specified in `site/IMAGE-PROMPTS.md`, with labeled placeholders until it lands. Docs stay close to the app: system stack, DESIGN.md neutrals, light/dark/system.

## Direction contract

THESIS: Lucia is a bench instrument that has taken the night shift. Its specs are read off glowing tubes, not icon cards. It refuses the dark dev-tool hero with a feature grid.

OWN-WORLD: blackened-steel chassis (#0e0e10), gunmetal panels, hairline anode-mesh gray, engraved Saira Extra Condensed caps, Saira body. Plasma orange (#ff8a00) is the only warm color, and only for lit digits, the primary action, and on-duty state. Glass tubes have nested ghost numerals.

STORY: the visitor learns that Lucia runs a homelab, sees the hardware and network it assumes, and trusts it because it asks before anything destructive. Then they install from source or star the repo.

FIRST VIEWPORT: left, the headline "Lucia takes the 2 a.m. shift." at about 90px condensed light caps, then the lede, then three controls (Install from source lit, Star, Desktop bootstrap unlit/COMING SOON). Right, the shift-clock instrument with 4 tubes reading 02:00 and a Mode/Owner/Status readout strip.

FORM: Nixie Laboratory Counter, a dealt challenger chosen over list position 6. Seed key 48a010b4. Signature interaction: tube banks slot-roll and settle when they enter view, static under reduced motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
